# Перетворення бакалаврського проєкту на магістерську роботу
> Тема: «Інтелектуальна система керування доставкою вантажів»

---

## 1. Нові модулі (що додати в код)

### AssignmentService — серце системи
Автоматично призначає курʼєра до замовлення замість ручного призначення адміном.

```
Вхід:  нове замовлення (адреса, вага, дедлайн)
Логіка: перебирає вільних курʼєрів → рахує cost для кожного → обирає мінімальний
Вихід: призначений курʼєр + оновлений статус замовлення → ASSIGNED
```

### PriorityService — пріоритизація черги
Сортує чергу замовлень перед призначенням:
```
priority = w1·(1/time_left) + w2·weight + w3·distance
```
Термінові важкі замовлення обробляються першими.

### RouteOptimizerService — маршрут курʼєра
Якщо курʼєр має кілька замовлень — будує оптимальний порядок об'їзду (спрощена задача комівояжера, nearest neighbor алгоритм).

### NotificationService — сповіщення
Telegram-бот як окремий компонент:
- клієнту: зміна статусу замовлення
- курʼєру: нове призначене замовлення
- використовує `telegrambots` бібліотеку, не LLM

### AnalyticsService — статистика для адміна
- середній час доставки по курʼєрах
- кількість замовлень за період
- навантаженість курʼєрів (для дашборду)

## 2. Математична модель

Це ключова відмінність магістерської від бакалаврської.

### Задача призначення (Assignment Problem)

**Множини:**
- `C = {c₁, c₂, ..., cₙ}` — множина доступних курʼєрів
- `O = {o₁, o₂, ..., oₘ}` — черга нових замовлень

**Змінна рішення:**
```
xᵢⱼ ∈ {0,1} — призначити курʼєра i до замовлення j (1) чи ні (0)
```

**Цільова функція — мінімізувати загальну вартість:**
```
F = Σᵢ Σⱼ cost(i,j) · xᵢⱼ → min
```

**Функція вартості:**
```
cost(i,j) = α·dist(i,j) + β·load(i) + γ·(1/priority(j))

де:
  dist(i,j)     — відстань від курʼєра до точки забору замовлення
  load(i)       — поточна кількість активних замовлень курʼєра
  priority(j)   — пріоритет замовлення (час до дедлайну, вага)
  α, β, γ       — вагові коефіцієнти (підбираються експериментально)
```

**Обмеження:**
```
Σⱼ xᵢⱼ ≤ MAX_LOAD      (курʼєр не може мати більше N замовлень)
Σᵢ xᵢⱼ = 1             (кожне замовлення призначається рівно одному курʼєру)
weight(j) ≤ capacity(i) (вага замовлення не перевищує вантажопідйомність)
```

### Алгоритми для порівняння (розділ 2 роботи)

| Алгоритм | Складність | Якість | Коли використовувати |
|---|---|---|---|
| Жадібний (Greedy) | O(n·m) | Середня | Мало курʼєрів/замовлень |
| Угорський (Hungarian) | O(n³) | Оптимальна | Середні масиви |
| Nearest Neighbor | O(n²) | Близька до оптимальної | Маршрутизація |

Реалізуєш **жадібний** як основний (простий, зрозумілий, достатній для магістра), угорський описуєш теоретично і порівнюєш результати на тестових даних.

## 3. Архітектурні зміни

### Поточна архітектура (бакалавр)
```
Browser → UserApplication (Spring MVC + WebSocket)
                ↑
         DriverApplication → Kafka → UserApplication
```

### Нова архітектура (магістр)
```
Browser / Telegram Bot
        ↓
  UserApplication (port 8081)
  ├── AuthModule
  ├── OrderModule
  ├── AssignmentModule  ← НОВИЙ (містить алгоритм)
  ├── PriorityModule    ← НОВИЙ
  ├── RouteModule       ← НОВИЙ
  ├── AnalyticsModule   ← НОВИЙ
  ├── NotificationModule← НОВИЙ (Telegram)
  └── WebSocket (real-time трекінг)
        ↑
  DriverApplication (port 8082) → Kafka → UserApplication
```

Все залишається в одному `UserApplication` — не треба розбивати на мікросервіси, це зайве для магістерської.

## 5. Зміни в БД

Мінімальні зміни в існуючих таблицях:

```sql
-- Таблиця courier: додати нові поля
ALTER TABLE courier ADD COLUMN capacity DOUBLE;        -- вантажопідйомність
ALTER TABLE courier ADD COLUMN telegram_id VARCHAR;    -- для Telegram сповіщень
ALTER TABLE courier ADD COLUMN is_available BOOLEAN;   -- доступність

-- Таблиця orders: додати пріоритет
ALTER TABLE orders ADD COLUMN priority INTEGER DEFAULT 0;

-- Нова таблиця: логи призначень (для аналітики)
CREATE TABLE assignment_log (
    id BIGSERIAL PRIMARY KEY,
    order_id BIGINT,
    courier_id BIGINT,
    assigned_at TIMESTAMP,
    algorithm_used VARCHAR,
    cost_value DOUBLE
);
```
